# MahasiswaProduktif
**Mahasiswa Produktif** adalah brand produk digital yang membantu mahasiswa mengelola perkuliahan, keuangan, tugas, aktivitas, dan perencanaan masa depan dengan lebih terstruktur. Melalui template planner, spreadsheet, dan berbagai tools produktivitas, kami hadir untuk membantu mahasiswa menjadi lebih terorganisir, produktif, dan siap berkembang.
